# DraftCheck — evaluation results

Generated by `python -m scripts.run_eval` from `outputs/eval/results.json`. Do not edit by hand.

Each drawing in `samples/generated/` runs through the real pipeline — extract, rules, then the correction loop — once per provider. Scores are computed in Python against the drawing's ground truth:

- **Dims found**: ground-truth dimensions matched by value. **Dims correct**: of those, value, tolerances and basic flag all right.
- **FCFs correct**: characteristic, tolerance, zone, modifier and datum letters all right. **Datums**: labels found.
- **Errors caught**: seeded errors a finding of the same rule caught. **False alarms**: findings that match no seeded error.
- **Fixes verified**: error-severity findings the correction loop cleared, as decided by re-running the rules. Warnings (MFG-001) do not start the loop and are not counted; a drawing with no error findings shows n/a.
- **Fallback**: Baseten did not answer in time and Meta answered instead, for at least one call.
